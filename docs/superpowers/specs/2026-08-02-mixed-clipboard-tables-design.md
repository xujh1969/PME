# 混合剪贴板表格设计

## 目标

粘贴包含普通文字和一个或多个表格的大段内容时，保留所有前后段落，并将其中可靠识别的 HTML 或 Tab 分隔表格转换为编辑器表格，维持原始顺序。

## 识别规则

- 优先使用剪贴板 HTML，按文档顺序提取文字块和所有 `table` 元素。
- HTML 只保留文字、换行和表格行列，不带入外部样式。
- HTML 无可用表格时扫描 `text/plain`。
- 纯文本中连续至少两行、每行至少两列且 Tab 列数一致时识别为一个表格。
- 普通行、空行或列数变化会结束当前表格；后续规则 Tab 行可开始新表格。
- 单行 Tab 和不规则 Tab 内容保持普通文字。
- 每个表格的第一行继续作为表头。

## 数据流

剪贴板内容先转换为有序片段：`text` 片段保存原始文字，`table` 片段保存二维单元格。`app.mjs` 将文字片段交给现有 `parseMarkdown`，将表格片段转换为现有 Tiptap 表格节点，最后一次性插入有序节点列表。

如果 HTML 解析未产生有效表格，则完整回退到纯文本分段，避免部分消费剪贴板内容。代码块、Mermaid、SVG、公式、现有表格单元格和纯文本粘贴模式继续使用原有路径。

## 边界

- 不修改 CSS 或任何样式文件。
- 不修改表格渲染、Markdown 全局解析器、复制/剪切、Tab 快捷键或 AI 功能。
- 不推断不完整表格，也不合并由普通文字分隔的两个表格。
- HTML 中复杂的合并单元格不展开推断；结构不规则时回退纯文本识别。

## 验证

- 前文、单个 TSV 表格和后文顺序完整。
- 一次粘贴中的多个 TSV 表格分别转换，中间文字保留。
- HTML 中多个表格及其前后文字按顺序转换，外部样式不进入文档。
- 单行或不规则 Tab 文本不转换。
- 现有纯表格粘贴、复制/剪切、Markdown 表格回归测试和生产构建继续通过。
